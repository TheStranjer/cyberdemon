# Recipes

To be written. Each recipe will be a worked end-to-end example — the request,
the measurements taken, the tool calls in order, the parameters chosen and
why, and the verification loop — for:

- Build a room of given size with a door and lights ("a 512×512 red key
  room").
- Turn a hand-drawn sketch into a playable first room.
- Turn a drawn texture image into a 128-wide tiling wall texture and apply
  it.
- Carve a corridor between two existing rooms.
- Add a secret with a switch that is findable but hidden.
- Make a space "scarier": which light levels, ceiling heights and textures
  actually change the feel, and how to confirm it rendered that way.
